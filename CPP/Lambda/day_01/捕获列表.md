

### **1. 捕获列表存在的原因**
**问题场景**：当 Lambda 需要访问其**外部作用域**的变量时（非全局变量）
```cpp
void func() {
    int count = 0;  // 局部变量
    
    // 错误！无法直接访问外部非静态局部变量
    auto lambda = [] { 
        count++;   // ❌ 编译错误：count 未声明
    };
}
```

**捕获列表的解决方案**：显式声明要捕获的外部变量
```cpp
int count = 0;
auto lambda = [count] {  // ✅ 正确：通过捕获列表访问
    // 这里可以读取 count 的值（但默认不能修改）
};
```

---

### **2. 捕获的两种核心方式**
#### **(1) 值捕获 (Capture by Value)**
- **特点**：创建外部变量的**副本**
- **语法**：`[var1, var2]`
```cpp
int a = 10;
auto lambda = [a] {  // 捕获时复制 a 的值
    std::cout << a;  // 输出 10（即使外部 a 改变）
};
a = 20;
lambda(); // 仍然输出 10
```

#### **(2) 引用捕获 (Capture by Reference)**
- **特点**：直接操作原变量
- **语法**：`[&var1, &var2]`
```cpp
int a = 10;
auto lambda = [&a] {  // 捕获 a 的引用
    a = 20;  // 直接修改外部变量
};
lambda();
std::cout << a; // 输出 20
```

---

### **3. 隐式捕获（偷懒写法）**
#### **(1) 捕获所有变量（慎用！）**
- `[=]`：以**值**捕获所有外部变量
- `[&]`：以**引用**捕获所有外部变量
```cpp
int x = 1, y = 2;
auto lambda1 = [=] { return x + y; }; // 值捕获 x,y
auto lambda2 = [&] { x++; y++; };     // 引用捕获 x,y
```

#### **(2) 混合捕获**
```cpp
int a = 1, b = 2;
auto lambda = [=, &b] { 
    // 值捕获 a，引用捕获 b 
};
```

### **4. 捕获列表解决了什么问题？**
#### **关键作用**：控制 Lambda 的**闭包行为**
- **场景1**：在异步回调中保留上下文
```cpp
void startAsyncTask(std::function<void()> callback) {
    // 假设在另一个线程执行 callback
}

void demo() {
    int retryCount = 3;
    startAsyncTask([retryCount] {  // 值捕获保留当前值
        if(retryCount > 0) { /* ... */ }
    });
}
```

- **场景2**：与 STL 算法结合
```cpp
std::vector<int> data {1, 2, 3};
int threshold = 2;
// 统计大于 threshold 的元素数量
auto count = std::count_if(data.begin(), data.end(),
    [threshold](int x) { 
        return x > threshold; 
    });
```

### **5. 需要特别注意的特性**
#### **(1) mutable 关键字**
- 允许修改**值捕获**的变量（默认 Lambda 的 `operator()` 是 `const`）
```cpp
int x = 0;
auto lambda = [x]() mutable {
    x++;  // 允许修改副本
    std::cout << x;
};
lambda(); // 输出 1
lambda(); // 输出 2（但外部的 x 仍然是 0）
```

#### **(2) 生命周期问题**
- **引用捕获**可能导致悬垂引用
```cpp
auto createLambda() {
    int localVar = 42;
    return [&localVar] {  // 危险！localVar 即将销毁
        std::cout << localVar; 
    };
} // localVar 离开作用域被销毁

auto lambda = createLambda();
lambda(); // 未定义行为！访问已释放的内存
```

### **6. 实际应用示例**
#### **示例1：计数器生成器**
```cpp
auto makeCounter() {
    int count = 0;
    return [count]() mutable {  // 值捕获 + mutable
        return ++count;
    };
}

auto counter = makeCounter();
std::cout << counter(); // 1
std::cout << counter(); // 2（每次调用保持独立状态）
```

#### **示例2：自定义排序规则**
```cpp
struct Person {
    std::string name;
    int age;
};

std::vector<Person> people = {/*...*/};
int targetAge = 30;

// 按与 targetAge 的年龄差排序
std::sort(people.begin(), people.end(), 
    [targetAge](const Person& a, const Person& b) {
        return abs(a.age - targetAge) < abs(b.age - targetAge);
    });
```

### **总结表格：捕获方式对比**
| 捕获方式         | 语法       | 修改权限 | 生命周期影响     | 典型用途               |
|------------------|------------|----------|------------------|------------------------|
| 值捕获           | `[x]`      | 需 mutable | 副本独立         | 需要快照数据           |
| 引用捕获         | `[&x]`     | 直接修改 | 依赖原变量     | 需要影响外部状态       |
| 隐式值捕获       | `[=]`      | 部分需 mutable | 副本         | 简单场景               |
| 隐式引用捕获     | `[&]`      | 直接修改 | 依赖原变量     | 需要多个外部变量时     |
| 混合捕获         | `[x, &y]`  | 混合权限 | 混合影响       | 精细控制               |

掌握捕获列表的关键在于理解：**你希望 Lambda 如何与外部环境交互**。通过合理选择捕获方式，可以写出既安全又灵活的代码。
