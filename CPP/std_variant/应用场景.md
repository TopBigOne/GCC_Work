# std::variant 完全指南

---

## 一、它是什么

`std::variant` 是 C++17 引入的**类型安全联合体**，本质上是一个"只能存一个值、但这个值可以是多种类型之一"的容器。

```cpp
std::variant<int, double, std::string> v;
v = 42;          // 现在存的是 int
v = 3.14;        // 现在改成存 double
v = "hello";     // 现在改成存 string
```

它类似于 C 语言的 `union`，但加上了完整的类型信息和生命周期管理。

---

## 二、解决了什么问题

### 问题 1：C union 不安全

传统 `union` 没有记录"当前存的是什么类型"，读错类型是未定义行为：

```cpp
// 危险！你必须自己记住当前存的是哪个字段
union Value {
    int i;
    double d;
    char* s;
};

Value v;
v.i = 42;
printf("%f\n", v.d);  // UB：实际存的是 int，却按 double 读
```

`std::variant` 在内部记录了当前活跃的类型，读错会抛出异常：

```cpp
std::variant<int, double> v = 42;
std::get<double>(v);  // 抛出 std::bad_variant_access，不是静默的 UB
```

### 问题 2：用继承+虚函数处理"有限类型集合"太重

当类型集合固定、不需要运行时扩展时，继承体系带来了不必要的开销：

```cpp
// 旧写法：为了多态，每个类型都要继承基类，堆上分配，虚表开销
struct Shape { virtual double area() const = 0; virtual ~Shape() {} };
struct Circle : Shape { double r; double area() const override { return 3.14 * r * r; } };
struct Rect   : Shape { double w, h; double area() const override { return w * h; } };

std::vector<std::unique_ptr<Shape>> shapes;  // 堆分配 + 指针间接
```

```cpp
// 新写法：值语义，栈上存储，无虚表
struct Circle { double r; };
struct Rect   { double w, h; };
using Shape = std::variant<Circle, Rect>;

std::vector<Shape> shapes;  // 连续内存，无堆分配
```

### 问题 3：`void*` 或枚举+联合的方案不类型安全

老式做法要手动维护类型标签，容易出错，且无法自动调用析构函数：

```cpp
// 老式做法，容易出 bug
enum class Tag { Int, String };
struct Any { Tag tag; union { int i; std::string* s; }; };
```

`std::variant` 自动管理构造和析构，支持非 POD 类型（如 `std::string`、`std::vector`）。

## 三、基本用法

### 3.1 声明和赋值

```cpp
#include <variant>
#include <string>

// 声明：可以存 int、double、string 三种类型之一
std::variant<int, double, std::string> v;

v = 42;       // 存 int（index = 0）
v = 3.14;     // 存 double（index = 1）
v = "hello";  // 存 string（index = 2）
```

### 3.2 读取值：std::get

```cpp
v = 42;

// 按类型读取（推荐）
int n = std::get<int>(v);

// 按索引读取
int m = std::get<0>(v);

// 类型不匹配时抛出 std::bad_variant_access
try {
    double d = std::get<double>(v);  // v 里存的是 int，会抛异常
} catch (const std::bad_variant_access& e) {
    std::cerr << e.what() << "\n";
}
```

### 3.3 安全读取：std::get_if（返回指针，不抛异常）

```cpp
v = 42;

if (const int* p = std::get_if<int>(&v)) {
    std::cout << "Int: " << *p << "\n";  // 匹配时，p 非空
} else {
    std::cout << "不是 int\n";           // 不匹配时，p 为 nullptr
}
```

### 3.4 类型检查

```cpp
v = 3.14;

// 方式 1：检查类型索引
std::cout << v.index();  // 输出 1（double 是第二个类型）

// 方式 2：直接检查是否持有某类型（推荐，更直观）
if (std::holds_alternative<double>(v)) {
    std::cout << "当前是 double\n";
}
```

### 3.5 std::visit：统一处理所有类型

`std::visit` 是配合 `std::variant` 最常用的工具，对 variant 当前存储的值调用对应的处理函数：

```cpp
// 方式 1：Visitor 结构体（重载 operator()）
struct Printer {
    void operator()(int v)         { std::cout << "int: " << v << "\n"; }
    void operator()(double v)      { std::cout << "double: " << v << "\n"; }
    void operator()(std::string v) { std::cout << "string: " << v << "\n"; }
};

std::variant<int, double, std::string> v = "hello";
std::visit(Printer{}, v);  // 输出: string: hello

// 方式 2：泛型 lambda（更简洁）
std::visit([](auto&& arg) {
    std::cout << arg << "\n";
}, v);
```

### 3.6 std::monostate：表示"空"状态

`std::variant` 默认用第一个类型值构造，如果需要"无值"状态，用 `std::monostate` 作为第一个类型：

```cpp
std::variant<std::monostate, int, std::string> v;  // 初始为空

v = 42;
if (v.index() == 0) {
    std::cout << "当前为空\n";
}
```

## 四、高阶用法

### 4.1 if constexpr + std::decay_t 类型分发

泛型 lambda 内通过编译期类型判断做差异化处理，是最常见的高阶模式：

```cpp
std::variant<int, double, std::string> v = 3.14;

std::visit([](auto&& arg) {
    using T = std::decay_t<decltype(arg)>;  // 去掉引用和 const，得到纯类型

    if constexpr (std::is_same_v<T, int>) {
        std::cout << "整数翻倍: " << arg * 2 << "\n";
    } else if constexpr (std::is_same_v<T, double>) {
        std::cout << "浮点平方: " << arg * arg << "\n";
    } else if constexpr (std::is_same_v<T, std::string>) {
        std::cout << "字符串长度: " << arg.size() << "\n";
    }
}, v);
```

> `std::decay_t` 的作用：`auto&&` 推导出的是引用类型（如 `const int&`），`decay_t` 去掉引用和 cv 修饰符，还原为 `int`，才能正确与 `std::is_same_v` 比较。

### 4.2 overloaded 技巧：内联多个 lambda

C++17 可以用模板聚合多个 lambda，实现类似 Visitor 结构体的效果，但写在调用处，更紧凑：

```cpp
// 工具模板（一次性定义，到处复用）
template<class... Ts>
struct overloaded : Ts... { using Ts::operator()...; };

template<class... Ts>
overloaded(Ts...) -> overloaded<Ts...>;  // C++17 推导指引

// 使用
std::variant<int, double, std::string> v = "world";

std::visit(overloaded{
    [](int arg)         { std::cout << "int: " << arg << "\n"; },
    [](double arg)      { std::cout << "double: " << arg << "\n"; },
    [](std::string arg) { std::cout << "string: " << arg << "\n"; },
}, v);
```

### 4.3 用 variant 实现有限状态机（FSM）

每个状态是一个独立的类型，状态转换就是给 variant 赋新值，状态数据直接附在类型上：

```cpp
struct Idle {};
struct Connecting { std::string host; int port; };
struct Connected  { std::string session_id; };
struct Error      { std::string message; };

using State = std::variant<Idle, Connecting, Connected, Error>;

State state = Idle{};

// 转换到"连接中"
state = Connecting{"192.168.1.1", 8080};

// 处理当前状态
std::visit(overloaded{
    [](Idle)              { std::cout << "空闲\n"; },
    [](const Connecting& s) { std::cout << "连接 " << s.host << ":" << s.port << "\n"; },
    [](const Connected& s)  { std::cout << "已连接，session: " << s.session_id << "\n"; },
    [](const Error& s)      { std::cout << "错误: " << s.message << "\n"; },
}, state);
```

**优势**：非法状态在类型层面无法表达（"已连接"状态里根本没有 host 字段），比枚举+标志位更安全。

### 4.4 错误处理：替代异常或错误码

用 `variant<Result, Error>` 表示"要么成功、要么失败"，比异常开销低、比错误码更清晰：

```cpp
struct ParseError { std::string reason; int line; };

using ParseResult = std::variant<int, ParseError>;

ParseResult parse_int(const std::string& s) {
    try {
        return std::stoi(s);
    } catch (...) {
        return ParseError{"不是合法整数", 0};
    }
}

auto result = parse_int("abc");

std::visit(overloaded{
    [](int val)              { std::cout << "解析成功: " << val << "\n"; },
    [](const ParseError& e)  { std::cout << "解析失败: " << e.reason << "\n"; },
}, result);
```

> 这个模式与 Rust 的 `Result<T, E>` 和 Haskell 的 `Either` 类似。

### 4.5 多 variant 联合 visit

`std::visit` 支持同时接受多个 variant，对所有类型组合进行分发：

```cpp
std::variant<int, std::string> a = 1;
std::variant<int, std::string> b = "hello";

std::visit([](auto&& x, auto&& y) {
    using TX = std::decay_t<decltype(x)>;
    using TY = std::decay_t<decltype(y)>;

    if constexpr (std::is_same_v<TX, int> && std::is_same_v<TY, int>) {
        std::cout << "两个 int 相加: " << x + y << "\n";
    } else {
        std::cout << "类型不匹配，跳过\n";
    }
}, a, b);
```

### 4.6 递归 variant：表达式树 / AST

表达递归结构（如语法树）时，用 `unique_ptr` 打破循环依赖：

```cpp
struct Number { double value; };
struct Add;
struct Mul;

using Expr = std::variant<
    Number,
    std::unique_ptr<Add>,
    std::unique_ptr<Mul>
>;

struct Add { Expr left, right; };
struct Mul { Expr left, right; };

// 递归求值
double eval(const Expr& e) {
    return std::visit(overloaded{
        [](const Number& n)               { return n.value; },
        [](const std::unique_ptr<Add>& a) { return eval(a->left) + eval(a->right); },
        [](const std::unique_ptr<Mul>& m) { return eval(m->left) * eval(m->right); },
    }, e);
}

// 构建 (2 + 3) * 4
Expr expr = std::make_unique<Mul>(
    Expr{std::make_unique<Add>(Expr{Number{2}}, Expr{Number{3}})},
    Expr{Number{4}}
);

std::cout << eval(expr);  // 输出 20
```

## 五、与相关工具对比

| 对比项 | `std::variant` | `std::any` | 虚函数继承 | C `union` |
|---|---|---|---|---|
| 类型集合 | 编译期固定 | 任意类型 | 运行时扩展 | 编译期固定 |
| 类型安全 | 编译期保证 | 运行时检查 | 运行时多态 | 无保证 |
| 非 POD 支持 | ✅ | ✅ | ✅ | ❌ |
| 性能 | 高（无堆分配） | 低（堆分配） | 中（虚表跳转） | 最高 |
| 适用场景 | 有限已知类型 | 完全未知类型 | 需运行时扩展 | 极致性能/C兼容 |

**选型建议**：
- 类型集合**固定且已知** → 优先 `std::variant`
- 类型集合**不确定**（插件系统、脚本引擎）→ 虚函数继承
- 需要存储**完全任意类型** → `std::any`
